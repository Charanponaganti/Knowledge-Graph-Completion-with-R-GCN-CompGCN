# ACL 2023 report sources

The final 12-page report is `../Knowledge_Graph_Completion_Report.docx` and
`../Knowledge_Graph_Completion_Report.pdf`, formatted from the supplied ACL
Word template. `main.pdf` is an identical copy of that Word-exported PDF.

`main.tex` contains the same revised narrative and generated result tables in
the existing ACL LaTeX style. It is generated by `../build_report.py` from
`../report_content.md` and the root `results.json`. No local TeX compiler was
available during revision; compiling this alternative source may produce
different pagination. The verified 12-page count applies to the Word export.

## Compile

From this folder, with a TeX install that has `pdflatex`
(MiKTeX or TeX Live):

```bat
pdflatex main.tex
pdflatex main.tex
pdflatex main.tex
```

Output: `main.pdf`.

Figures are read from `../figures/` (the PNGs copied from the Kaggle run).
If a figure is missing, copy it from the repo root `figures/` folder into
`report/figures/` first.

Overleaf: upload this `latex/` folder plus `report/figures/*.png`, set
`main.tex` as the compiler root, compiler = pdfLaTeX.
